URL Shortener API · v1.0

Live

🚀 A simple and powerful API that lets you shorten long URLs and redirect them with ease.

📘
How to Use

Send a POST request to /shorten with the following JSON body:

request body · json 
{
  "originalUrl": "https://www.example.com"
}

You'll receive a response with a shortened URL like:

response · json 
{
  "shortId":  "abc123",
  "shortUrl": "https://yourdomain.com/abc123"
}
🔁
Redirection

Visiting /abc123 will redirect the user to the original URL.

🌐
API Routes
  • POST /shorten Shorten a URL
  • GET /:shortId Redirect to original URL
