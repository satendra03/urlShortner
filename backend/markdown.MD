# 🔗 URL Shortener App

A minimal and powerful web application that converts long URLs into short, easy-to-share links. Ideal for reducing clutter, simplifying sharing, and tracking link usage (if analytics enabled).

## ✨ Features

- ✅ Convert long URLs to short ones instantly
- 🔁 Automatic redirection to the original URL
- ✍️ Optional support for custom aliases (e.g., `/my-link`)
- ⏳ Optional link expiration (temporary links)
- 📊 Click analytics and usage tracking (if implemented)
- 🎯 Clean, intuitive UI for quick use
